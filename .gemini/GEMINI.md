# VLM CoT Generator

## 1. Python Virtual Environment

This project utilizes `uv` for Python virtual environment and dependency management.

### 1.1 Usage and Constraints

-   **Package Management**: Use `uv` instead of standard `pip`. To check installed packages, run `uv pip list`.
-   **Installation Policy**: Never install packages without explicit user permission.
-   **Dependency Requests**: If a package is required, ask the user for the specific package name and version before proceeding.
-   **Code Execution**: Execute Python with `uv run python <script>`.
